Обоснование
Положительная оценка с запасом на шум пилота; учтены стоимость и пересечение с пилотами.

Это предложения агента для финального запуска. Остатки среды выше отражают уже проведённые пилоты; параметры финальных кампаний передаются оценщику отдельно.

04Почему агент выбрал этот план

  • Сформировано 252 гипотез; история используется как слабое начальное предположение.
  • Получено 20 валидных наблюдений; оценки обновлены с учётом размера выборки.
  • Выбрано 1 кампаний без повторов среди финальных контактов.
Допущения при построении прогноза
  • Исторические переходы другой выборки используются только для слабого начального ранжирования.
  • Шум пилота: опубликованное стандартное отклонение 0.804 / sqrt(n); модель нормального среднего является приближением.
  • Интервал оценки описывает шум пилота, но не гарантирует перенос эффекта на более узкие подгруппы.
  • ID пилотных контактов не доступны. Пересечение с пилотами учтено приближённо по вероятности отбора; финальные аудитории не пересекаются.
  • expected_net_gain — прогноз дополнительного эффекта финальных кампаний после пилотов, а не результат судейства.

Синтетическая локальная среда. Наблюдения пилотов содержат шум. Прогноз агента не является результатом скрытого судейского скоринга.
Отчёт работает без интернета. Для повторного прогона: python demo.py --seed 42.
