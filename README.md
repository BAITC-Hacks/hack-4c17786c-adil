## Агент управления тарифными кампаниями

Проект для кейса HackAlem AI / Beeline: исследовать аудиторию, проверить гипотезы пилотами и сформировать от 1 до 10 маркетинговых кампаний с учётом бюджета, охвата и неопределённости эффекта.

**Статус:** согласуемая архитектура и план реализации. Рабочий агент и интерфейс ещё не реализованы.

- [Архитектура, ограничения и этапы разработки](docs/architecture.md).
- Разработка, документация и проверяемые изменения ведутся в этом репозитории через ветки и pull requests.
- Данные кейса синтетические; результаты не описывают реальные показатели Beeline.

Планируемая точка входа: `agent.py` с классом `Agent` и методом `act(env)`. Обязательный результат сдачи: воспроизводимый `submission.csv`, полученный штатной командой `python make_submission.py` из пакета участника.
